# Local Model Router для GitHub Copilot App

Пересылаемый экспериментальный пакет для сценария:

- основная модель: локальная Senior-модель, уже импортированная в Copilot App из провайдера (в исходном эксперименте — Qwen Senior через oMLX);
- младшие роли: Junior-модель, уже импортированная в Copilot App из провайдера (в исходном эксперименте — Qwen Junior через oMLX);
- интерфейс: GitHub Copilot App;
- компьютер: MacBook Pro с 48 ГБ unified memory;
- цель: проверить, может ли Copilot plugin перехватывать уже созданное делегирование и заменять профиль саб-агента на подходящий профиль с закреплённой моделью.

Пакет не меняет встроенный режим `Auto` и не является собственным model gateway. Он реализует более узкую и проверяемую гипотезу:

1. Пользователь назначает, какая из уже импортированных в Copilot App моделей — Senior, а какая — Junior.
2. Senior решает вызвать инструмент `task`.
3. `preToolUse` hook видит этот вызов.
4. В режиме `audit` hook безопасно фиксирует структуру аргументов.
5. После подтверждения схемы режим `rewrite` может заменить выбранный профиль агента.
6. Поле `model:` выбранного профиля направляет запрос в назначенную Junior-модель.

## Что находится в архиве

- локальный Copilot marketplace;
- plugin `local-model-router`;
- Senior-orchestrator и три Junior-профиля;
- настройка ролей Senior/Junior по каталогу Copilot-imported моделей;
- slash-команда `/set-model-roles` и skill назначения ролей;
- audit-first hook и отключённый по умолчанию режим rewrite;
- детерминированная начальная routing policy;
- скрипт обнаружения импортированных моделей и подстановки их ID;
- автономные unit-тесты hook и role setting без Copilot и oMLX;
- небольшой fixture-репозиторий для сквозной проверки;
- подробная инструкция по установке и acceptance test plan.

## С чего начать

1. Прочитать [INSTALL-COPILOT-APP.md](INSTALL-COPILOT-APP.md).
2. В Copilot App импортировать провайдера и убедиться, что модели видны в model picker.
3. Назначить Senior и Junior из этого каталога (`configure-models.mjs --list`, затем `--senior` / `--junior`).
4. Выполнить локальные тесты plugin.
5. Установить marketplace через Copilot CLI и полностью перезапустить App.
6. Пройти сначала audit-тесты из [TEST-PLAN.md](TEST-PLAN.md).
7. Включать `rewrite` только после подтверждения реального поля agent ID в `toolArgs`.

## Важная граница

Hook не может сам инициировать делегирование и не выбирает модель основного сеанса. Он может изменить только уже предложенный Senior вызов `task`. Поэтому основной сеанс для этого эксперимента должен быть явно зафиксирован на назначенной Senior-модели, а не на `Auto`.

Версия пакета: `0.2.0` — настройка Senior/Junior из Copilot-imported моделей поверх совместимости с актуальным Copilot plugin/hooks API.
