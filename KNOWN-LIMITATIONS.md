# Известные ограничения

1. Plugin не расширяет встроенный список моделей Copilot `Auto` и не выбирает primary model.
2. Hook работает только после того, как Senior предложил `task`. Если Senior выполняет простую задачу сам, hook не создаёт саб-агента.
3. Схема `task.toolArgs` официально не зафиксирована. Audit обязателен для каждой существенно новой сборки App.
4. Поддержка hooks как компонента App документирована на уровне plugin, но конкретное срабатывание и mutation в App является acceptance test этого прототипа.
5. Неверный или неразрешимый `model:` может молча привести к модели родительского сеанса. Только oMLX DEBUG-log доказывает фактическую модель.
6. Родительский `Auto` игнорирует pin дочернего agent-профиля. Для эксперимента parent должен быть явно Senior.
7. Plugin-agents имеют низкий приоритет при конфликте имён. Поэтому все профили используют уникальный префикс `local-router-`.
8. Локально установленный plugin и локальный oMLX недоступны cloud sandbox/coding agent. Тестировать нужно в локальной App-сессии.
9. Command `preToolUse` hook при crash или ненулевом exit code блокирует tool; timeout, напротив, fail-open. Скрипт перехватывает свои ошибки и возвращает `{}`, но это не заменяет мониторинг.
10. Keyword classifier — стартовая policy, а не обученный роутер. Он намеренно оставляет неизвестные задачи Senior.
11. Headroom, очередь, межсессионный lock и глобальный concurrency cap ещё не реализованы. На 48 ГБ соблюдайте `max_active_junior=1` вручную.
12. Изменение файлов plugin требует переустановки и новой App-сессии из-за кеша.
13. Локальный ZIP нельзя установить кнопкой в App. Для UI-only установки нужен Git custom marketplace.
