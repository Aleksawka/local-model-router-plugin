# Известные ограничения

1. Plugin не расширяет встроенный список моделей Copilot `Auto` и не выбирает primary model сеанса. Он только назначает роли Senior/Junior моделям, уже импортированным в App.
2. У Copilot plugin нет нативного экрана Settings для выбора модели; настройка — `config/model-roles.json`, CLI `configure-models.mjs` и slash-команда `/set-model-roles`.
3. Обнаружение каталога Copilot App с диска best-effort: формат локального store App официально не зафиксирован. Пустой `--list` требует экспорта ID из picker.
4. Hook работает только после того, как Senior предложил делегирование (`task` / `Agent`). Если Senior выполняет простую задачу сам, hook не создаёт саб-агента.
5. Схема аргументов делегирования официально типизирована как `unknown`. Hook принимает `toolArgs`, `tool_args` и `tool_input`, включая JSON-строку, но audit всё равно обязателен для каждой существенно новой сборки App.
6. Поддержка hooks как компонента App документирована на уровне plugin, но конкретное срабатывание и mutation в App является acceptance test этого прототипа.
7. Неверный или неразрешимый `model:` может молча привести к модели родительского сеанса. Только DEBUG-log провайдера доказывает фактическую модель.
8. Родительский `Auto` игнорирует pin дочернего agent-профиля. Для эксперимента parent должен быть явно Senior.
9. Plugin-agents имеют низкий приоритет при конфликте имён. Поэтому все профили используют уникальный префикс `local-router-`.
10. Локально установленный plugin и локальный oMLX недоступны cloud sandbox/coding agent. Тестировать нужно в локальной App-сессии.
11. Command `preToolUse` hook при crash или ненулевом exit code блокирует tool; timeout, напротив, fail-open. Скрипт перехватывает свои ошибки и возвращает `{}`, но это не заменяет мониторинг.
12. Keyword classifier — стартовая policy, а не обученный роутер. Он намеренно оставляет неизвестные задачи Senior.
13. Headroom, очередь, межсессионный lock и глобальный concurrency cap ещё не реализованы. На 48 ГБ соблюдайте `max_active_junior=1` вручную.
14. Изменение файлов plugin требует переустановки и новой App-сессии из-за кеша. Это относится и к смене Senior/Junior.
15. Локальный ZIP нельзя установить кнопкой в App. Для UI-only установки нужен Git custom marketplace.
